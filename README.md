# c-programming
A collection of C programming concepts, practice programs, and projects developed while learning C from the basics.


C is a general-purpose, procedural programming language used to develop system software, application software, embedded systems, operating systems, and many other applications.

C was designed to provide:
Efficiency
Portability
Low-level memory access
Fast execution

2. History of C
C was developed by Dennis Ritchie at Bell Laboratories.
It was developed around 1972.
C evolved from earlier programming languages such as BCPL and B.
It became widely popular because of its efficiency and portability.

3. Features of C
Simple – Easy to learn compared with many low-level languages.
Procedural – Programs are divided into functions/procedures.
Fast – C programs generally execute efficiently.
Portable – C programs can be compiled on different platforms with relatively few changes.
Middle-level language – Provides both high-level programming features and low-level memory manipulation.
Structured – Supports structured programming using functions, loops, and conditional statements.
Extensible – New functionality can be added using functions and libraries.
Memory management – Provides direct memory access using pointers.

4. Applications of C
C is commonly used in:
Operating systems
Embedded systems
Device drivers
Compilers
System software
Networking software
Microcontroller programming
Games and performance-critical applications


5. Basic Structure of a C Program
#include <stdio.h>
int main()
{
    printf("Hello World");
    return 0;
}


6. Explanation
#include <stdio.h>
Includes the Standard Input/Output library, which provides functions such as printf().
int main()
The main() function is the starting point of execution of a C program.
printf()
Used to display output on the screen.
return 0;
Indicates that the program completed successfully.

7. Important Terms
Term	Meaning
Compiler	Converts C source code into machine/object code
Source Code	Program written by the programmer
Function	A block of code that performs a specific task
Header File	Contains declarations for library functions
main()	Starting function of a C program
printf()	Used to display output

8. C Program Execution

Source Code
    ↓

    ↓

    ↓
Linker
    ↓
